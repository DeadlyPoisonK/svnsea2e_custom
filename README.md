# svnsea2e_custom

Fork personal del sistema **7th Sea Second Edition (Unofficial)** para Foundry VTT, basado en [Detailing-the-Realm/svnsea2e](https://github.com/Detailing-the-Realm/svnsea2e).

## Por qué existe este fork

El repo oficial lleva mucho tiempo sin cambios (últimos commits solo de mantenimiento, sin releases nuevas). Envié mensajes y propuestas de cambios (issues/PRs) al equipo original y no obtuve respuesta — el oficial acumula 14 issues y 9 PRs abiertos sin resolver.

Ante eso, tomé el código base y armé mi propio fork para poder seguir arreglando bugs y agregando funcionalidad sin depender de que el mantenedor original responda.

## Estado respecto al oficial

- Base tomada de `Detailing-the-Realm/svnsea2e`, versión `4.0.0` (compatibilidad Foundry `13.341`).
- Historial propio desde `Initial commit` (importación del oficial) → `v23` → `v23.1` (cambios propios).
- Remote propio: `DeadlyPoisonK/svnsea2e_custom` (ya no apunta al repo oficial).
- El oficial distribuye desde `src/` compilado con Vite; este fork usa el build ya compilado (`svnsea2e.mjs`, `svnsea2e.css`) como base de trabajo directo.

## Qué es este repo

Sistema completo para Foundry VTT (13.x): hojas de personaje, villano, bruto, monstruo y barco, ítems (ventajas, trasfondos, hechicería, sociedades secretas, etc.), traducciones (en/de/fr/es/it/pt-BR).

## Contacto

Si encontrás un problema, algo roto, o tenés una sugerencia: contactame directamente a mí (dueño de este fork), no al repo oficial. Cambios y fixes se manejan acá.
